# 六上數學特訓｜紙筆作答・即時對答案・錯題本・A4 出卷

> 專為國小六年級資優生打造的數學自主學習系統。結合「課本原型題」、「奧數思維天梯 (AMC 8 對標)」與「早餐 5~10 分鐘免動筆純腦力體操」，支援實體紙筆手寫、線上即時對答案、自適應終身錯題本與 A4 考卷動態排版列印。

---

## 🌟 核心特色

1. **三軌訓練維度**：
   - 📖 **課本原型題**：100% 涵蓋翰林版六上全冊 8 大單元例題與隨堂練習，穩固學校課本算理。
   - 🪜 **奧數天梯 (L1~L5)**：對標亞太盃、AMC 8 等資優競賽深水題，培養見招拆招的競賽邏輯。
   - 🧠 **早餐純腦力體操 (1★~10★)**：全冊 160 題深度選擇題，**完全不需動筆計算**，利用早餐 5~10 分鐘啟動數感、奇偶性、倍數特徵與極值構造。
2. **手寫紙筆 + 線上即時診斷**：
   - 先在實體紙筆計算，再上網即時對答案，保留珍貴演算推導痕跡。
   - 三態作答自評（👍 我算對了 / ⏳ 算對但想很久 / ❌ 我有算錯），精準識別熟練度盲點。
3. **終身錯題本消滅戰**：
   - 自動記錄弱點題目與錯誤次數，支援單元篩選與單題重做，答對自動消滅出庫。
4. **🖨️ A4 實體考卷排版引擎**：
   - 自由勾選單元、自訂題數（3~15題）、草稿方格尺寸（35mm / 50mm / 70mm）。
   - 考卷右上角自動生成**動態 SVG QR Code**，學生寫完拿 iPad 掃碼即可一秒直達線上對答案。
5. **📤 AI 教研閉環匯出**：
   - 一鍵打包學生錯題、盲點代碼與歷史戰績，產生資優教研出題 System Prompt Markdown，無縫對接 LLM 自動派生新題。

## 📱 iPad「加入主畫面」免連網使用 (PWA)

1. 在 iPad 上使用 **Safari** 瀏覽器開啟本網站。
2. 點擊瀏覽器右上角的 **分享（Share）** 按鈕。
3. 向下滑動並選擇 **「加入主畫面」（Add to Home Screen）**。
4. 完成後，iPad 桌面即會出現「六上數學」獨立 App 圖示，點開即可全螢幕沈浸式操作，無網址列干擾！
