# 六上數學特訓｜紙筆作答・即時對答案・錯題本・A4 出卷

> 專為國小六年級資優生打造的數學自主學習系統。結合「課本原型題」、「奧數思維天梯 (AMC 8 對標)」與「早餐 5~10 分鐘免動筆純腦力體操」，支援實體紙筆手寫、線上即時對答案、自適應終身錯題本與 A4 考卷動態排版列印。

---

## 🌟 核心特色

1. **三軌訓練矩陣 + 期末四大單元 4D 滿血版（全庫 841 張題卡／925 個作答點）**：
   - 📖 **課本原型題**：涵蓋翰林版六上全冊 8 大單元例題與延伸變式（U05~U07 擴充至 20 題、U08 完整升級 25 題）。
   - 🪜 **奧數天梯 (L1~L10)**：對標亞太盃、AMC 8 等資優競賽深水題（U05~U08 均升級為 20 題，涵蓋 L5~L10 均勻分佈）。
   - 🧠 **早餐純腦力體操 (1★~10★)**：U05~U08 各 20 題全面去除國中/成人代數符號並升級 4D 選擇題，培養數感與幾何／邏輯直覺。
2. **🎯 新版 4D 實戰考場 (`arena.js`)**：
   - 三層級聯篩選（單元／題庫來源／難度分級）、**練習模式 vs 模擬考**、與 **🙈 遮住選項（先紙筆後對答案）** 雙軌作答體驗。
   - **作答後 4 維度深度診斷**：維度一「考點核心」、維度二「小六無代數分步算理」、維度三「逐選項陷阱抓包與 48 項 `trapCode`」、維度四「幾何 SVG／線段圖與心法」，搭配 3 模組 **舉一反三與延伸自修** (`extensionStudy`)。
   - **無損遷移**：透過 `legacyId` 映射自動無損保留 `Rex` 原 U05~U08（140 題）錯題與熟練統計。
3. **📐 國小六年級親切數學排版引擎 (`kids_math.js`)**：
   - 自動繪製課本樣式除法直式（含小數點向右移位標記與餘數對齊）、乘法直式、加減直式、上下疊式帶分數／真分數、線段比例圖與幾何步驟 SVG 圖解（`{ type: "svg" }`）。
   - 全站學生可視區嚴格做到零 `*`、`^`、`\frac` 或 `x/y` 成人代數符號外洩。
4. **🖨️ A4 實體考卷雙軌排版引擎（學生空白卷 ＋ 家長詳解卷）**：
   - 自由勾選單元、個人錯題本交叉出題、自訂題數與 35/50/70mm 5mm 手寫草稿格。
   - 一鍵切換 **「📄 學生空白卷」**（嚴格零答案外洩）與 **「🔑 家長詳解卷」**（鎖定同一批題目與順序，印出直式步驟、線段圖與陷阱剖析）。
   - 考卷右上角自動生成**動態 SVG QR Code**，iPad 掃碼即可直達線上對答案並自動消滅錯題。
5. **🏆 六校名校段考全真題庫 (方案 C 雙模)**：
   - 完整收錄臺北西松、新北桃子腳、高雄獅湖、高雄忠孝、桃園普仁、臺南和順等 6 校第一次段考全真試卷，共 215 題，支援原圖 Lightbox 切換。
6. **🔊 互動音效、5 段字級切換與裝置 RWD 適配**：
   - 內建純 Web Audio 合成音效 (`sound.js`，含靜音切換)、導覽列 **5 段字級縮放 (90%~140%)**。
   - 移除耗能毛玻璃改為高對比實色卡片，針對 Desktop、iPad 10.2" (`768~1120px`) 與 iPhone 15 Pro (`<= 640px`) 適配單手觸控與直式滑動防切邊。
7. **👥 4 人學習帳號隔離 & ☁️ Firebase 防呆同步**：
   - 內建 `🦖 Rex`（正式學員，`🔒 保護中`）與 `🧪 Test 1`、`🔬 Test 2`、`🛠️ Test 3`（測試帳號，支援跨裝置 `resetAt` 重置）。
   - 整合 Firebase Realtime Database 雙向同步，強化「空本機裝置絕對禁止覆蓋雲端歷史紀錄」守衛與僅同步永久統計（隔離本機作答暫存）。
8. **🔥 題號盤 3 數字統計與淨錯誤熱力圖視覺矩陣**：
   - 抽屜盤每題顯示中央序號、左上綠字累計答對、右上紅字累計答錯，並依淨錯誤 `err - ok` 呈現 6 階熱力色階。

## 📱 iPad「加入主畫面」免連網使用 (PWA)

1. 在 iPad 上使用 **Safari** 瀏覽器開啟本網站。
2. 點擊瀏覽器右上角的 **分享（Share）** 按鈕。
3. 向下滑動並選擇 **「加入主畫面」（Add to Home Screen）**。
4. 完成後，iPad 桌面即會出現「六上數學」獨立 App 圖示，點開即可全螢幕沈浸式操作，無網址列干擾！
